3. ERROR DEL FORMULARIO DE ELIMINACION
---------------------------------------

Problema:
El formulario para eliminar estaba ubicado despues de @endsection y fuera
del ciclo @forelse. En ese lugar la variable $aprendiz podia no existir,
especialmente cuando no habia registros.

Solucion:
El formulario se movio dentro del ciclo @forelse, de modo que cada aprendiz
tiene su propio formulario y su propia ruta de eliminacion.


4. VISTA DE EDICION
--------------------

Problema:
El controlador tenia el metodo edit(), pero no existia el archivo:

resources/views/aprendices/edit.blade.php

Solucion:
Se creo la vista edit.blade.php. Esta vista:

- Muestra el formulario para editar un aprendiz.
- Envia los datos a la ruta aprendices.update.
- Usa el metodo HTTP PUT.
- Incluye el token CSRF.
- Reutiliza el formulario compartido _form.blade.php.
- Muestra los errores de validacion.
- Incluye un enlace para volver al listado.


5. ERROR EN EL FORMULARIO COMPARTIDO
-------------------------------------

Problema:
El archivo _form.blade.php comenzaba con "div>" en lugar de "<div>".
Esto generaba HTML incorrecto al mostrar el formulario.

Solucion:
Se agrego el signo "<" faltante para convertirlo en una etiqueta HTML valida.


6. ERROR DEL PARAMETRO DE RUTA EN EDITAR
-----------------------------------------

Problema:
Route::resource('aprendices', AprendizController::class) generaba rutas con
el parametro {aprendice}, pero el controlador esperaba un modelo llamado
$aprendiz:

public function edit(Aprendiz $aprendiz)

Ademas, el StoreUpdateAprendizRequest buscaba el parametro con el nombre
'aprendiz'. Como los nombres no coincidian, Laravel no podia resolver
correctamente el modelo al abrir o actualizar la edicion.

Solucion:
Se configuro el nombre del parametro en routes/web.php:

Route::resource('aprendices', AprendizController::class)
    ->parameters(['aprendices' => 'aprendiz']);

Ahora las rutas usan {aprendiz} y coinciden con el controlador, la vista y
el FormRequest.


7. VALIDACIONES REALIZADAS

Se ejecutaron estos comandos correctamente:

- php artisan route:list --name=aprendices
